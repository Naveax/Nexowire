ChatGPT’ye bağla

Bilgisayarını BAĞLA ile hesabına ekledikten sonra bu adımı bir kez tamamla.

  1. ChatGPT’de Eklentiler / Plugins → + → Özel MCP sunucusu ekle ekranını aç.
  2. Adı Nexowire, kimlik doğrulamayı OAuth seç. Aşağıdaki sunucu adresini kullan.
  3. Eklentiyi oluşturup yükle; cihazını bağladığın aynı GitHub hesabıyla giriş yap.
  4. Yeni sohbette @Nexowire seç ve “Cihazlarımı listele” yaz.
