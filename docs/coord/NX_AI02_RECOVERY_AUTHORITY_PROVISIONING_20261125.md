## Implemented

Dedicated authority SQLite schema (not the Hub SQLite ledger): one stable independently observed recovery transaction hash, unique authorization ID and unique sealed envelope hash. One reserve, one seal, one consume CAS, no reset/delete/reissue API. Reserve is durable before signing, seal is durable before publishing, consume is durable before effect. Any lost acknowledgment, crash, timeout or ambiguous write must deny automatic retry; a consumed grant is NOT evidence of execution or terminal success. Scope and signed envelope SHA-256 are exactly bound; changed request binding, device, times or bytes deny. Requires explicitly provisioned authority/store IDs, on-disk WAL, synchronous=FULL and no surrounding transaction. Thirty-second TTL is a provisional maximum for this storage component, subject to independent review of deployment time source. SQL statements are parameterized; the connection must be exclusively owned by the protected authority composition root. No private key, signer call, external receipt validator, task launch, scheduler change, automatic migration or live database access.
