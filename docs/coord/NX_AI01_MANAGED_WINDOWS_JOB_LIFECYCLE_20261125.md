## Source changes
- Managed Node launches opt into the existing guardian's v6 protocol; no fallback to v5 on a stale binary. New independent kernel readback checks guardian FILETIME/session, plus prior root FILETIME, exact Job handle membership and limit flags. Native parent handle, actual parent/guardian same SID/elevated token and session, suspended root session; Session 0 additionally requires LocalSystem SID. Restrict inherited handles to the three duplicated stdio pipes with STARTUPINFOEX handle list. No process resumes before prior kernel gate and native DACL seal. Historical legacy command format is not represented as v6.
- Cooperative STOP writes a cancellation request to the same unique local Job control directory. Async request wait <= 1s; a late write can only request stop of that session, not grant activation. Native guardian polls cancellation/owner/deadline, uses retained Job HANDLE with TerminateJobObject, queries ActiveProcesses==0 (5s observation budget), and verifies retained root handle signaled before publishing exclusive flushed terminal record. Optional managed runtime budget 1..600000 ms; omitted means no runtime deadline, not proof of containment. v6 failure exits use disjoint 512 after managed admission parsing. Local terminal record binds exact launched root PID/FILETIME and guardian PID, reason and native exit status. Two-second bounded readback; missing, corrupt, wrong identity, signals, failed publication and unknown cleanup stay UNKNOWN. No PID-only kill in new stop path.
- Volatile and durable consumers use that local observation and pipe drain; guardian death/root PID absence no longer suffice for v6 local exited. Durable worker preserves early output and orphaned state, bounded external pipe drain; existing manager shutdown rejects unresolved owned volatile Jobs. Unknown control directory evidence retained. Local cleanup does not prove any external COM process is stopped.
- Standalone startup preflight no longer invokes unreviewed PowerShell COM native sink. Returns MACHINE_STARTUP_NATIVE_ISOLATION_REQUIRED before effects on Windows. Existing scheduled launcher inline read-only evidence script unchanged. This intentionally blocks direct Broker install/start/on/auto until a protected native provider is supplied; STOP/OFF are unchanged. Online update denial, SYSTEM migration/uninstall/recovery denial and #402 baseline/audit unchanged.
