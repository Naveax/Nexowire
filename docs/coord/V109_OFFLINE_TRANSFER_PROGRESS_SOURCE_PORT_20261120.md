# Offline transfer progress source-only review (2026-11-20)

Origin: a standalone progress summarizer was proposed in historical Draft #1107. Current upstream candidate #1160 at `bacd4c992d31538645c4ae6d132cedc4d4cbce1d` does not contain this feature. This stacked source review starts from Draft #1237 HEAD `3b32dc961012921a756be69d03bfc2a8f6ece9a8` and ports the concept without merging the obsolete PR's other reporting changes.

The new `summarizeOfflineTransferProgress` helper in `src/ops/scale-transport-metrics.ts` is in-memory, returns `SYNTHETIC_EVIDENCE_ONLY` or `UNKNOWN`, and never performs an artifact write, transfer, retry, OS effect or credential operation. A claimed transferred byte total is not a verified final digest/commit receipt. Only declared COMPLETE or ALREADY_PRESENT with all bytes acknowledged *and* a supplied finalReceiptVerified flag may yield 100%. Even this is caller-supplied **synthetic evidence, not a real device completion proof**. Phase failures, inconsistent sent/received/acknowledged counters, invalid numbers and non-boolean receipt flags fail closed. Retried sent bytes may exceed the original file size.

Five test cases in `test/ci/scale-offline-transfer-progress.test.ts` exercise blocked premature completion, valid terminal state, retried streams, malformed counters, and zero-length transfers. This test lives directly under `test/ci/` so the repository's existing one-level `npm test` discovery executes it. The existing 35-file reviewed Portable Root lane retains its file count; `pure-import-provenance.mjs` must pin the changed transport source (old blob `5a3dc9c36e0dda54d2d448e95e6d2e2f3dcfb828`, new blob `bb79ba0635f862dfb19f92b9d4a461bc185cde48`) because another existing reviewed root test imports that source.

Acceptance is the exact-HEAD GitHub General CI plus Portable Root Node22/24 and Test Discovery. This **does not prove** actual user-to-user transfer, remote device operation, restart, Windows SYSTEM authority or release readiness. No changes to `main` or release publication are implied.
