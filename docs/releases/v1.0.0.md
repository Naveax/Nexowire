# Nexowire v1.0.0

Nexowire v1.0.0 is the first stable self-hosted release of the first-party ChatGPT computer-control runtime.

## Highlights

- First-party outbound Native Agent transport with reconnect continuity, bounded request deduplication, mutation-safe replay boundaries, and relay fallback.
- Stable MCP surface v1 with frozen backward-compatible input contracts and machine-readable structured-output semantics.
- Multi-device routing with persistent device identity, aliases, groups, deterministic routing policies, capability-aware discovery, and fail-closed ambiguity handling.
- Durable process I/O, persistent task graphs, resumable runbooks, artifact verification, audit history, idempotency records, and bounded event feeds.
- Windows control for processes, services, registry, scheduled tasks, Event Log, firewall, environment, windows, screenshots, clipboard, keyboard, UI Automation, and pointer fallback.
- First-party Edge/Chrome/Chromium CDP automation with DOM actions, screenshots, and exact-element visual verification.
- WSL2, Linux, and macOS native execution with real CI coverage.
- Production security foundation with TLS, rotating/revocable credentials, roles/scopes, OIDC/JWT identity, protected secret stores, deployment doctor, onboarding, and live revocation tests.
- Windows privileged broker with DPAPI-protected bootstrap secrets and verified per-user scheduled-task lifecycle.
- Windows control and environment PowerShell payloads use explicit UTF-8 stdin rather than child-process environment variables.
- Verified service-control postconditions and bounded Windows Event Log textual output.
- 45 validated shipped skills, including a stable v1 skill-library baseline and conservative domain recipes.
- Release candidates include SHA256SUMS, a release manifest, CycloneDX SBOM, independent verification, and SLSA/SBOM attestations.

## Distribution

v1.0.0 is distributed as a GitHub Release for self-hosted deployments. npm publication remains intentionally disabled for this initial release.

## Compatibility

The ChatGPT-facing MCP v1 compatibility floor is stable. Future additive capabilities and domain recipes must preserve the existing v1 input and structured-output contracts unless a new explicit MCP surface version and migration path are introduced.
