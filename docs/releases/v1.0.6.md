# Nexowire v1.0.6

CORE physical-console control is time-unbounded and revocable after an actual
local Windows enrollment. FULL or an enabled preference alone does not grant
physical input. The native Agent now uses the DPAPI-protected local profile,
signed current D1 authority and native Windows admission implemented in #863.

- Revalidate owner/device/installation, issuer and generation on every input.
- CORE OFF, SAFE, re-pairing, revocation and verification loss deny access.
- Preserve valid enrollment across restart; retain separate timed grants.
- Local KAPAT/STOP cancels input and persists revocation before network cleanup.
- Reject lock screen, UAC Secure Desktop, elevated targets and request replay.
- Keep preference, local enrollment and effective physical status separate.

Apply migration 0019 and deploy the matching control plane before enrollment.
Update Agent, Hub and Broker using verified official artifacts; configure the
trusted paired authority origin. Legacy local-only devices need owner pairing.
Each PC needs its own real local first consent; remote approval does not replace it.

Publication waits for the existing successful CI run at the exact main SHA.
The stable update channel and stable-only publication policy remain in force.
No previous immutable release or tag is replaced.

Live acceptance is separate from source/CI success. Roll out work-pc first,
verify versions/enrollment/input and OFF/STOP, then proceed to Naveax. Do not
claim physical access from a scheduled update ACK or saved CORE preference.
