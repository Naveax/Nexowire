## Threat model and limitations

This is **a verifier of declared, synthetic manifest coverage**, not a complete runtime import graph discovery system. It intentionally takes no filesystem input and performs no Windows API call. A dishonest source could omit delay-loaded/dynamically resolved DLLs, config-driven script imports, alternate paths or updater payloads while claiming an exhaustive inventory. It is **not** production admission and never becomes trusted on its own.

Source bundle bytes use a deterministic JSON/base64 fixture container, **not ZIP/MSI/Authenticode**. Cryptographic Ed25519 signature checks genuinely operate on fixture bytes and independently supplied test keys, but the keys are generated by the unit tests and do **not** represent first-party Nexowire publisher trust or a genuine external authority. A successful self-signed source fixture does not prove real publisher, handle, SID, DPAPI access or ACL effective denial.

Old Agent 1.0.5 safety requires production release artifacts, authenticated version negotiation, immutable image/handle provenance, valid owner epoch, independently durable anti-rollback witness, and safe rollback after a real forced crash, all separately reviewed. A timestamp, task name, PID, `consent.exe` visibility, or `SYSTEM:true` field is never OS attestation.

## Adversarial tests

The new isolated tests cover signed manifest changes, attacker Ed25519 keys, wrong target/rollback signer pins, all transitive PE import digest/publisher mismatch, truncated/missing/extra files, unresolved imports, unreachable extras, unknown dynamic imports, ADS, path traversal, hardlinks, reparse points, inherited Authenticated Users Modify despite Deny, old bundle tamper/partial package, wrong previous Agent version, Hub skew, offline stale DPAPI blob, wrong owner/device, old/replayed epoch, signed witness substitution, old key not revoked, interrupted UNKNOWN, and original Agent removed before authenticated handoff.

No test is skipped or intentionally weakened. The exact commit SHA and its CI results must be recorded independently; parent CI success is not sufficient.
