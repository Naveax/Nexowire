## Reproduce (no npm installation or browser required)

From K05 code branch (created on the baseline upstream `main`):

```sh
node --test test/delegated/k05/audit-owner-web.test.mjs
node scripts/delegated/k05/audit-owner-web.mjs .
```

Second command deliberately exits 1 if source findings exist, so a red scanner run must **not** be reported as PASS. To compare with the owner Draft, use a separate read-only checkout of exact commit `94d38799e9e4b50fe84f7924e6fc84f90aeba090`:

```sh
node scripts/delegated/k05/audit-owner-web.mjs /path/to/owner-1068-checkout
```

The tool reads only `web/{connect.html,connect.js,index.html,app.js,admin.html,admin.js,styles.css}` in the chosen checkout and does not mutate them. It performs targeted source pattern checks, which **may miss runtime defects or produce false positives** on different JavaScript spellings. Its `SOURCE_ONLY`, `NOT_RUN` fields are mandatory interpretation limits.
