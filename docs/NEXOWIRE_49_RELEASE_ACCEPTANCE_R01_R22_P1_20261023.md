1. **Contain:** stop admitting new *mutating* tasks at an **independently authoritative ingress**, not merely a UI flag. Mark all in-flight or lost-ACK effects `UNKNOWN/RECONCILE_REQUIRED`, never `SUCCESS` or auto replay.
2. **Fence writers:** identify published checkpoint versus staged bytes, stop all artifact writers with independently verifiable owner/job fencing, and ensure a final publisher cannot race a revoked epoch. Keep quarantine and digest refs. Do **not** release quota or delete artifacts until signed writer-stop + independently checked deletion/postcondition.
3. **Assess trust state:** if external CAS/writer stop cannot be verified, halt rollback automation; request manual containment with HIGH/Broker disabled. Do not jointly restore journal and authority snapshots as a “fix”; [#587](https://github.com/Naveax/Nexowire/issues/587) proves this may re-admit old IDs. Do not erase WAL, receipts or UNKNOWN journal evidence.
4. **Restore binaries only with trusted mechanism:** operator authorizes a signed, version-compatible, protected-path rollback manifest and performs the approved local canary. Recheck Authenticode, EXE/DLL dependency closure, file owner/ACL, runtime signer/image identity, broker token, service health and device identity. If the trusted installer or rollback channel is absent, **leave native mutations OFF**; manual recovery required.
5. **Reconcile:** use independent Agent/Hub/CAS issuer readback for *the original* logicalMutationId/requestId/jobId/checkpointId. Preserve UNKNOWN if after-effect state cannot be established; do not clone ID or rerun mutations as a recovery substitute. Validate no stale pre-rollback owner epoch can redispatch.

Never disable UAC, weaken ACL, force-kill unrelated processes, delete affected files or claim an original incident closed merely because a test turned green.
